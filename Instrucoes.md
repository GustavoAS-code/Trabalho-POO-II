# Instruções para execução
primeiramente certifique-se de ter o python instalado em sua máquina
## Linux
**Primeira vez rodando:** você deve criar uma venv e instalar as dependencias do projeto:

```
python3 -m venv venv
```

**Obrigatório:** Para rodar o projeto, você deve entrar na venv:


```
source venv/bin/activate
```

**Primeira vez rodando:** Se as dependencias nunca foram instaladas:

```
pip install pyside6
```

**Obrigatório:** em seguida rode o comando para executar o programa principal:

```
python3 main.py
```

## Windows
para rodar o projeto você deve digitar o seguinte comando:

```
python main.py
```
